A program that writes one original sentence (110 characters) to replace an entire pointless meeting: nobody in the room can approve anything, so the meeting is twelve people waiting for the one person who never showed up.

## Run it

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
